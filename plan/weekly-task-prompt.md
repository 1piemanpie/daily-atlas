Weekly Daily Atlas task: write the next region week for the game.

Source of truth is the repo 1piemanpie/daily-atlas (site https://1piemanpie.github.io/daily-atlas/). Start from the latest main. Read these first and follow them exactly:
- plan/rules.md: Micah's standing content rules (US English audience; weeks alternate easy = Americas/western Europe and hard = everything else, never front-loading the easy ones; cover every country's major first-level subdivisions over time, grouping minor ones with discretion, e.g. Chad; places come back forever with NEW facts, never repeated ones; landmark hints for every warm-up city; licensed photos with credits on fact cards).
- plan/schedule.md: take the next week in the queue, then move it to Done and append one new week so the queue stays about ten weeks long and keeps alternating.
- plan/coverage.json: the places for each country and the visit log. Add each new day to its country's visits.
- Project memory (design rules) and UPGRADES.md.

Build it the same way the Mexico & Caribbean week was built: its own map with 25+ tappable regions (mapgen/), warm-up cities with landmark hints you can see on satellite imagery (mapgen/pinhints.json, then `node genpinll.mjs`), flags, visual fact cards with PHOTOS where a picture helps, a sources file in sources/, a passing no-spoiler check and a full browser playthrough with no errors. Keep 2 to 3 weeks written ahead of today. Then run `python3 build.py`, commit to a `claude/weekly-<region>` branch, push, open a PR into main and merge it yourself (squash) once build.py, the no-spoiler check and the playthrough all pass, so the week goes live on the site with no manual step (Micah asked for automatic merges on 2026-10-27). If any check fails and you can't fix it, leave the PR open and say what's blocking. After merging, republish https://claude.ai/artifact/QKMB6ub5gHHyrZEqBfrQGg with the same supporting files (data/, img/), save a copy to /mnt/project-files/daily-atlas/, update memory, and post a short summary in this thread.
